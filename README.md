# 2D Projectile Toolkit

A lightweight, modular and extensible projectile toolkit for Unity 2D.

> **Status:** Early development — v0.1.0

## Goals

- Simple to install and integrate into existing Unity projects.
- Compose projectile movement and behaviours instead of creating a class for every projectile type.
- Keep the runtime lightweight and independent from optional visuals.
- Provide useful defaults while remaining easy to extend.

## Planned v0.1

- Projectile core and lifecycle
- Straight and homing movement
- Projectile spawner
- Object pooling
- Pierce, bounce, explode and split behaviours
- ScriptableObject projectile configuration
- Sample playground
- Optional sample VFX

## Requirements

- Unity 2022.3 LTS or newer
- 2D project

## Installation

In Unity, open **Window > Package Manager**, choose **Add package from git URL**, and use:

```text
https://github.com/hoang111py/unity-2d-projectile-toolkit.git
```

The public API and installation instructions may change while the package is in early development.
